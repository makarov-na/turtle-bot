# Описание доработки

## Функции модуля моторов:

* Отключение моторов
* Остановка моторов (силовое торможение)
* Установить линейную скорость в точке середины оси колёс
* Установить угловую скорость в точке середины оси колёс

## Настройки:

* Диаметр колёс, мм
* Колёсная база, мм
* Максимальная скорость, мм/с 

# Техничские детали:

## Программа:

* Нужно сделать скетч для ардуино.
* Функции реализовать в методах stop, power_stop, set_speed(linear_speed, angular_speed)
* Для проверки в главном цикле сделать вызов set_speed(0, 0) и отключить через 10 секунд вызовом stop()

## Модуль моторов состоит из:

* arduino nano
* драйвер моторов L298N Stepper DC Motor Driver
* моторы с энкодерами

## Подключение 

Подключение правого мотора:
* D2-IN1
* D3-IN2
* D5-ENA
* D10,D11 - энкодер

Подключение левого мотора:
* D4-IN3
* D7-IN4
* D6-ENB
* D8,D9 - энкодер

Рабочий прототип реализован на arduino nano src/motor_controller/motor_controller/motor_controller.ino
Ничего из прототипа переносить не нужно. Нужно использовать для уточнений по подключению и направлениям моторов.
