## 1a. Диагностика движения (закрыта — причина найдена на железе)

- [x] 1a.1 Наблюдения: `set_speed 0.0` не останавливает бот; `set_speed -30.0` не едет назад; колеса идут неравномерно (замедление/ускорение). Гипотеза windup объясняет только первый симптом — нужны данные контура
- [x] 1a.2 Добавить диагностическую телеметрию в ack: `mL/mR`, `oL/oR`, `iL/iR` (измеренная скорость, ШИМ-выход, интеграл каждого колеса), собрать 8174 B / 26%; PTY-тесты controller.py 15/15 PASS
- [x] 1a.3 По телеметрии установить причину и зафиксировать исправление в контуре — см. 1a.4–1a.6
- [x] 1a.4 **Знак обратной связи инвертирован.** После переноса энкодеров на Port C (A0–A3) каналы A/B на обоих колёсах поменялись местами → счёт и measured имеют неверный знак. Вращение колеса вперёд руками давало `mL=mR≈-495`, а моторы уходили в o=255 в ту же сторону (положительная обратная связь): «самораскрутка», «не тормозит», «не едет назад». Фикс: инверсия всей `QUAD_TABLE` (эквивалент swap A/B); `motorSign` и направление моторов не тронуты. Проверка руками: левое вперёд → `mL>0`, oL уходит в −122 (тормоз против руки); правое → `mR>0`, oR до −135
- [x] 1a.5 **Недостаточный запас усилия привода.** Порог трогания редуктора (56:1) ~55–65 ШИМ; при лимите интеграла 200 контур мог выдать максимум Kp·30+Ki·200=85 PWM — целевые 30 не достигались, баг «звук есть, нет движения». Фикс: `PID_INTEGRAL_LIMIT 200→500` и feedforward `PID_FF=255.0f/V_MAX_MM_S≈0.85`; `out = FF·setpoint + Kp·error + Ki·integral + Kd·deriv`. Собрано 8226 B / 26%
- [x] 1a.6 **Рывок/самораскрутка после паузы.** После долгой остановки `controlLoop` не работал, и при возобновлении `dt` и `prevTicks` были устаревшими: `dt`≈полной длительности паузы → гигантский фейковый вклад интеграла (наблюдались `iL=±296` и мотор, крутящийся несколько секунд). Фикс: в `controlLoop()` при `gap>200мс` сброс `prevTicks=ticks` и `gap=10мс`. Проверка на полу: возобновление после паузы 2 с → `iL≈4.5` без скачка, заем поворот чистый. Собрано 8336 B / 27%
- [x] 1a.7 Прогон на полу (прошивка с 1a.4–1a.6): FWD 50 → measured 25–42, стоп `power_stop`, FWD снова без рывка, НАЗАД −50 → measured −25…−42 — все три исходных симптома устранены
