# Tasks: Телеметрическая панель в консольном пульте

Tasks break down implementation. PTY-тесты controller.py живут вне репозитория
(`/tmp/opencode/test_controller.py`) и юнит-тесты (`/tmp/opencode/test_controller_units.py`)
— сидят на изменениях run()/рендера.

## 1. Парсинг и хранилище телеметрии

- [x] 1.1 Добавить `parse_ack(line) -> Ack|None`: из строки `ack <n> <v> <w> mL=.. mR=.. oL=.. oR=.. iL=.. iR=..` извлекать float/int поля; невалидные строки → `None`
- [x] 1.2 Добавить `Ack` (dataclass) и кольцевой буфер `TelemetryRing` (`deque(maxlen=20)`) с методом `push(ack)` и `clear()`
- [x] 1.3 Юнит-тест парсера/кольца: валидная строка, битые поля, >20 значений удерживают последние 20, `clear()`

## 2. Рендерер панели (ANSI)

- [x] 2.1 Чистая функция `format_row(ack) -> str`: фиксированные колонки `# v w mL mR oL oR iL iR` (обрезка/дополнение до ширины экрана — отдельно в `crop()` на уровне `render_panel`)
- [x] 2.2 Чистая функция сборки панели `render_panel(status, rows, footer, cols) -> str`: статус, заголовок, 20 строк (свежие сверху), футер; обрезка до `cols`; инверсия последней строки (`\x1b[7m…\x1b[0m`, до инверсии строка кропается, чтобы `\x1b[0m` не терялся на узких экранах)
- [x] 2.3 Юнит-тест рендера: новые сверху, обрезка ширины, инверсия только последней строки

## 3. Терминальные переходы и интеграция в controller.py

- [x] 3.1 Вход в панель: `\x1b[?1049h` + `\x1b[?25l`; выход: `\x1b[?25h` + `\x1b[?1049l` в `finally`/`atexit` рядом с восстановлением termios
- [x] 3.2 Перевести `out()`-сообщения (подключение, «Связь потеряна», подсказки) в слоты панели: статус-строка/футер; убрать прямые `print` из интерактивного цикла (`out()` удалён, `print` не используется)
- [x] 3.3 В `run()`: накапливать входящие байты в буфер до `\n` (rfcomm режет строки), полные строки → `parse_ack` → `TelemetryRing.push`; рендер после пачки новых ack; ограничение буфера `MAX_RX_BUFFER = 512`
- [x] 3.4 При успешном переподключении — `TelemetryRing.clear()` и перерисовка панели
- [x] 3.5 Статусная строка с абсолютными значениями: `lin +30% (90.0 мм/с)  ang -10% (-0.32 рад/с)`
- [x] 3.6 Ширина экрана перед рендером через `shutil.get_terminal_size()` (stdout) с fallback 80 при `winsize == 0`; без привязки к `SIGWINCH`
