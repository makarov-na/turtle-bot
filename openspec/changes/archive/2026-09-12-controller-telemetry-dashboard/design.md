# Design: Телеметрическая панель в консольном пульте

## Context

`controller.py` — единственный stdlib-пульт (termios/tty/select), heartbeat 200 мс, raw-режим терминала, автореконнект. Сейчас ack-телеметрия бота читается и выбрасывается (строки 197–202 в run()); статус показывает только проценты. Прошивка не меняется — ack уже содержит `n v w mL mR oL oR iL iR`.

Ограничения терминала в raw-режиме: `OPOST` выключен → переводы строк только явные `\r\n`; весь вывод идёт через `sys.stdout`; текущий `out()` печатает поверх (реконнект-сообщения ломали бы полный экран).

## Goals / Non-Goals

**Goals:**
- Полноэкранная живая панель (alt-screen): статус + таблица последних 20 ack, новые сверху, подсветка последнего.
- Абсолютные значения команды в статусе.
- Корректный вход/выход из alt-screen, показ сообщений внутри панели.
- Чистые функции парсинга/форматирования — тестируемые без TTY.

**Non-Goals:**
- Аномалии/подсветка отклонений (i у лимита, measured vs set) — возможная v2.
- Пауза отрисовки пробелом.
- Графический GUI/веб; изменение прошивки или протокола.
- Полноценный TUI-фреймворк (curses нужен, потому что raw + отрисовка «кокпита» своя).

## Decisions

### 1. Полноэкранный режим через alternate screen buffer, без curses

При входе в панель: `\x1b[?1049h` (alt-screen) + `\x1b[?25l` (скрыть каретку); при выходе: `\x1b[?25h` + `\x1b[?1049l`. Отрисовка — прямой вывод ANSI: к исходной позиции `\x1b[H`, панель постоянной высоты. Альтернативы: curses (переключает экран своим способом, конкурирует с `tty.setraw`, но даёт окна и цвета) — для 22 строк излишен; простой скролл (вариант A) — отклонён пользователем.

Обоснование высоты: статус (1) + заголовок (1) + 20 строк таблицы + футер = 22 строки, помещается в стандартный 24-строчный терминал; на высоких экранах таблица используется как есть, на узких шириной — строки обрезаются под `cols`.

### 2. Два состояния приложения: «панель» и «реконнект»

Всё, что сейчас печатает `out()` (подключение, «Связь есть», «Связь потеряна»), переводится во фрейм панели: статус-строка сообщения + футер-подсказки. Рендер — единственный владелец экрана (`renderer.render(...)`), из внешнего кода запрещены прямые `print`. При реконнекте после успешного `open_serial` кольцевой буфер очищается (требование spec) и панель отрисовывается заново.

### 3. Поток данных: ack → парсер → кольцо → рендер

В `run()` при `fd in r` байты накапливаются в буфер до `\n`, полные строки передаются парсеру; неполные строки (rfcomm режет) ждут следующих чтений. Парсер возвращает `Ack(n, v, w, mL, mR, oL, oR, iL, iR)` (float/int) или `None` для невалидных. `deque(maxlen=20)` хранит последние 20. Рендер вызывается после каждой пачки новых ack (не чаще раза за heartbeat). Форматирование строки — чистая функция от `Ack`, ширины колонок фиксированные.

Подсветка последней строки — инверсия через `\x1b[7m ... \x1b[0m`.

### 4. Рендер устойчив к ширине экрана

Перед каждым рендером `shutil.get_terminal_size()` (stdout); строки таблицы обрезаются до `cols` байт, чтобы избежать переносов в raw-режиме. `SIGWINCH` обрабатывать не обязательно — панель перерисовывается каждые ~200 мс и подхватит новый размер сама.

## Risks / Trade-offs

- [Панель ломается, если что-то печатает мимо рендерера (например, `out()`) во время работы] → весь вывод переводится в слоты панели; `out()` больше не используется в интерактивном цикле.
- [Длинные ack на узком терминале переносятся/ломают сетку] → обрезка по `cols`; фиксированная ширина колонок.
- [Реконнект-сообщения между сроками живого стола] → они живописные в футере/статусе, не поверх.
- [Рендер каждые 200 мс жрёт CPU/задержки heartbeat] → 22 строки за эпизод, тривиально; heartbeat-цикл не блокируется рендером.

## Migration Plan

1. Добавить чистые модули: `parse_ack()` и `TelemetryRing` (deque) + форматтеры таблицы — покрыть PTY/юнит-тестами.
2. Перевести `run()` на «панель»: alt-screen, рендер-состояние, сообщения в панели.
3. Свернуть статус-строку с абсолютными значениями.
4. Проверить на PTY: существующие тесты controller.py остаются зелёными; новый тест — приход 20+ ack, панель отрисовывает последние 20, топ — последний.
5. Ручной прогон на железе: `controller.py /dev/rfcomm0`, наблюдать панель, реконнект, выход — экран восстанавливается.

## Open Questions

- Подсветка отклонений (v2): порог `|mL − v|`, подсветка интегрорирования у лимита — решится отдельным маленьким change'ом при необходимости.
- Нужна ли колонка `w` (угловая) в таблице или достаточно `v`? Влияет на ширину строки.
