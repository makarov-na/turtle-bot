## Context

Текущее состояние firmware motor_controller.ino:
- Arduino Nano управляет двумя DC моторами через L298N (D2-D7)
- Два энкодера JGB37-520 подключены к D8-D11 (PCINT)
- Hardware Serial (D0/D1) используется CH340 для USB-подключения к PC
- D12, D13, A0-A7 свободны
- Нет вывода какой-либо информации — firmware работает автономно

Ограничения Arduino Nano:
- 1 Hardware Serial (занят CH340/USB)
- SoftwareSerial ограничен ~9600 baud стабильно
- Hardware interrupts (INT0/INT1) заняты моторами
- Pin-change interrupts (PCINT0) заняты энкодерами

## Goals / Non-Goals

**Goals:**
- Установить беспроводной канал связи Arduino → PC через HC-06
- Первый шаг: передача текстового сообщения "hello PC from ARDU" каждую секунду
- Сохранить возможность прошивки через USB (CH340) параллельно
- Использовать level shifter для корректного преобразования уровней логики

**Non-Goals:**
- Приём команд от PC на Arduino (передача в одну сторону, TX only)
- Высокоскоростная телеметрия (9600 baud достаточно для первого шага)
- Изменение существующей логики моторов
- Добавление новых сенсоров

## Decisions

**1. SoftwareSerial на D12/D13 вместо Hardware Serial (D0/D1)**
- D0/D1 заняты CH340 (USB-загрузка, отладка)
- SoftwareSerial на D12/D13 не конфликтует с USB
- 9600 baud — достаточно для HC-06 и текстовой телеметрии
- Альтернатива: перенести Pi на I2C, HC-06 на D0/D1 — отклонено (сложнее, не нужно на данном этапе)

**2. Level shifter BSS138 4-ch вместо резистивного делителя**
- Level shifter — готовый модуль, проще подключить
- Би-directional, не нужно думать о направлении
- Делитель дешевле, но требует расчёта резисторов и занимает больше места на макетке
- Оба варианта работают, level shifter надёжнее

**3. HC-06 питается от отдельного 5V (Cedar buck converter)**
- Не нагружает стабилизатор Arduino Nano
- 5V доступна с Cedar buck converter (до 10A)
- HC-06 имеет встроенный стабилизатор 3.3V — принимает 5V на VCC

**4. Формат сообщения — простой текст**
- "hello PC from ARDU" — начальное тестовое сообщение
- Текстовый формат легко читаем в Bluetooth Serial Terminal на PC
- В будущем можно перейти на JSON/бинарный формат

## Risks / Trade-offs

**[SoftwareSerial блокирует прерывания]**
→ SoftwareSerial использует timer и прерывания для приёма данных. При 9600 baud это минимальное влияние, но при высокой нагрузке возможны пропуски символов. Митигация: для первого шага (отправка каждую секунду) риск пренебрежимо мал.

**[HC-06 нестабилен при питании от USB]**
→ Если HC-06 питать от Arduino 5V pin (через USB), возможны просадки напряжения. Митигация: HC-06 питается от отдельного Cedar buck converter.

**[9600 baud — низкая скорость]**
→ Для будущей полной телеметрии (энкодеры, PID, датчики) 9600 baud может быть недостаточно. Митигация: на данном этапе это не критично; HC-06 поддерживает до 1382400 baud через AT-команды (но это потребует level shifter на更高的 скорости).
