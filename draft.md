
## Краткое описание задачи

* У нас появилась возможность работать с контроллером через HC-06
* Необходимо реализовать передачу управляющих команд с компьютера на контроллер 
* Команды должны соответствовать протоколу set_speed(linear_speed, angular_speed)
* Для управления с ПК необходимо реализовать консольное приложение с обработкой кнопок стрелок на клавиатуре.

## Что конкретно нужно сделать

* Из основного скетча убрать все тестовые функции
* Добавить получение команд с компьютера
* Приложение надо написать на питоне. Изначально передаются данные 0,0
* Кнопка up прибавляет 10% к скорости, кнопка down убавляет 10%
* Кнопка left прибавляет 10% к угловой скорости, кнопка right убавляет 10%
* Скрипт надо разместить в папке со скетчем
